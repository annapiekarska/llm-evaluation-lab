# LLM Evaluation Lab

Portfolio project focused on evaluating LLM-generated answers against source context using AI Quality Engineering criteria such as groundedness, faithfulness, completeness, relevance, hallucination risk, human review and quality gates.

## Status

In progress.

## Project goal

The goal of this project is to demonstrate how LLM outputs can be evaluated from a Quality Engineering and AI Governance perspective without training or building a language model.

This project focuses on:

- LLM output quality
- evaluation criteria
- test dataset design
- scoring
- human review
- reporting
- quality gates
- risk-based AI evaluation
